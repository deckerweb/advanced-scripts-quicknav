# Advanced Scripts QuickNav 1.2.0-rc2

Lokaler Testkandidat vom 1. Oktober 2026.

Installation: Das Plugin-ZIP über Plugins → Plugin hinzufügen → Plugin hochladen installieren und eine vorhandene Version ersetzen. Advanced Scripts muss aktiv sein; WordPress 6.7+ und PHP 8.0+ werden benötigt.

Einstellungen → Advanced Scripts QuickNav: Favoriten wählen und speichern. In der Toolbar aktive/inaktive Scripts und Ordner öffnen. Ein deaktivierter Elternordner erzeugt den Hinweis Durch Ordner deaktiviert. Script hier anlegen öffnet den nativen Erstellungsdialog.

Die vom Benutzer gewählte Variante A (Code Compass) ist enthalten. Alle Pakete enthalten ausschließlich QuickNav und die gemeinsamen deckerweb-Komponenten, keinen Premium-Quellcode.

Die umfassende WordPress-Integrationsmatrix ist ausdrücklich verschoben. Das Paket wurde nicht als öffentliche stabile Version veröffentlicht. Favoriten bleiben bei Deaktivierung erhalten.

## Was sich gegenüber rc1 geändert hat

- Die Vollbildeditor-Option und sämtliche zugehörigen Anpassungen sind entfernt.
- Favoriten werden als Karten mit direkten Editor-Links dargestellt. Die Karten aktualisieren sich beim An- und Abwählen; die Toolbar nach dem Speichern.
- Die Statistik zeigt Snippets insgesamt, aktiv, inaktiv, Ordner, gespeicherte Favoriten und durch Ordner blockierte aktive Snippets sowie die Typverteilung.
- Das Changelog-Modal zeigt formatiertes HTML mit Versionsüberschriften, Datum, Listen und Kategorie-Badges. Diese Gestaltung ist als gemeinsamer Plugin-Footer-Standard hinterlegt.

Vorhandene Favoriten bleiben beim Ersetzen des Plugins erhalten. Für den Test das bisherige Plugin mit dem neuen ZIP ersetzen; nicht parallel installieren.
