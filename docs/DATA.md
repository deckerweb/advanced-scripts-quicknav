# Data, connections and licenses

[Deutsch](DATA-de.md)

Favorites and display preferences use user metadata keyed by site ID. Deactivation and uninstall preserve these preferences and all Advanced Scripts code. Uninstall clears the repository update cache; Library cleanup follows its last-installed-host contract, preserving shared data while another host remains installed. No destructive data-removal option is offered.

Updates contact GitHub for public release metadata and package downloads. The embedded Library’s online catalog is optional and initially disabled; its settings explain those connections. Local graphics and scripts are bundled; no telemetry is collected.

The deckerweb Library 1.1.0 and GitHub Updater 2.2.1 are maintained by David Decker under GPL-2.0-or-later. Sources: https://github.com/deckerweb/deckerweb-plugin-library and https://github.com/deckerweb/deckerweb-updater. QuickNav artwork is original deckerweb artwork. The bundled Code Compass SVG files contain native vector shapes, gradients and Inter text converted to paths, without embedded raster images or external asset URLs. Inter is licensed under SIL OFL 1.1; see assets-github/FONT-LICENSE.txt. Search sends only titles, folder paths, type/status metadata and personal favorite state to your browser, never script contents; favorite stars use the existing per-user/site preference store. Advanced Scripts premium code is not bundled.
