# Daten, Verbindungen und Lizenzen

[English](DATA.md)

Favoriten und Anzeigeoptionen stehen in Benutzermetadaten mit Website-ID. Deaktivierung und Deinstallation erhalten diese Einstellungen und sämtliche Advanced-Scripts-Inhalte. Deinstallation bereinigt den Repository-Updatecache; die Library folgt ihrem Vertrag für den letzten installierten Host und erhält gemeinsam benötigte Daten, solange ein anderer Host installiert ist. Es gibt keine destruktive Löschoption.

Updates rufen GitHub für öffentliche Release-Metadaten und Downloads auf. Der Onlinekatalog der Library ist optional und anfangs ausgeschaltet; ihre Einstellungen erläutern die Verbindungen. Grafiken und Skripte liegen lokal vor. Keine Telemetrie.

Die deckerweb Library 1.1.0 und der GitHub Updater 2.2.0 stammen von David Decker und stehen unter GPL-2.0-or-later. Quellen: https://github.com/deckerweb/deckerweb-plugin-library und https://github.com/deckerweb/deckerweb-updater. QuickNav-Grafiken sind eigene deckerweb-Grafiken. Die mitgelieferten Code-Compass-SVG-Dateien enthalten native Vektorformen, Verläufe und Inter-Schriftpfade, keine eingebetteten Rasterbilder oder externen Asset-URLs. Inter steht unter SIL OFL 1.1; siehe assets-github/FONT-LICENSE.txt. Die Suche überträgt ausschließlich Titel, Ordnerpfade, Typ-/Statusmetadaten und den persönlichen Favoritenstatus an deinen Browser, keine Script-Inhalte. Die Favoritensterne verwenden die vorhandenen Einstellungen pro Benutzer und Website. Advanced-Scripts-Premium-Code wird nicht mitgeliefert.
