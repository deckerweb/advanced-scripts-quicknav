# Advanced Scripts QuickNav 1.2.0-rc2

Local test candidate, October 1, 2026.

Install the plugin ZIP via Plugins → Add New → Upload Plugin, replacing the previous installation. Requires active Advanced Scripts, WordPress 6.7+ and PHP 8.0+. Select favorites under Settings → Advanced Scripts QuickNav.

The user-selected variant A (Code Compass) is included. Packages include no Advanced Scripts premium source. Full WordPress integration validation is explicitly deferred; this is not a public stable release. Deactivation retains favorites.

[FAQ](wiki/English.md) · [Changelog](CHANGELOG.md)

## Changes from rc1

- Removed fullscreen-editor preferences and adjustments.
- Added directly linked favorite cards and immediate selection previews. Save applies the selection to the toolbar.
- Added total, active/inactive, folder, saved-favorite and active-but-folder-blocked counts, plus type distribution.
- Formatted the modal as HTML with version/date headings, lists and category badges; recorded it as the shared plugin-footer standard.

Replace the existing plugin with this ZIP. Saved favorites remain intact. Do not install a second copy.
