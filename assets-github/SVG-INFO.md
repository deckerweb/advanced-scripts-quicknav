# Code Compass artwork

English and German banners use Inter, licensed under SIL OFL 1.1; see FONT-LICENSE.txt. Text is converted to native vector paths. SVGs contain vector shapes, paths and gradients, with no embedded raster images, live font references, filters or external resources. The icon contains no text.
